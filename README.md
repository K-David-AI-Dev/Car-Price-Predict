# Car Price Prediction Project 🚗💰

This is my first official project as a beginner developer. It focuses on predicting used car prices based on a market dataset using Machine Learning.

## 🤖 AI Collaboration
This project was developed in collaboration with **Lumina (Gemini)**. The AI assisted in code optimization, debugging, and guiding the deployment process to GitHub. This partnership allowed me to build a clean and functional solution while learning the best practices of modern software development.

## 📝 Project Overview
The goal of this application is to estimate the market value of used cars by analyzing various features such as manufacturing year, mileage, fuel type, and more.

## 🛠️ Tech Stack
- **Language:** Python
- **Key Libraries:** Pandas, Scikit-learn, Pickle
- **Model Storage:** The trained model is stored in the `car_price_full_pipeline.pkl` file.

## 🚀 How to Use
To run the prediction locally, ensure you have the following files in your directory:
1. `predict.py` – The main script for making predictions.
2. `car_price_full_pipeline.pkl` – The pre-trained model pipeline.

Run the following command:
```bash
python predict.py
